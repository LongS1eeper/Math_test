# 과외 시험 · 자동채점 사이트

> **처음이시면 [START.md](START.md) 부터 보세요.** 설치→배포까지 25분 순서대로 정리해 뒀습니다.

학생이 **집에서도** 시험을 보고, 자동 채점받고, **해설을 온라인으로** 보고, 오답노트에
유형별로 쌓입니다. 채점이 끝나면 선생님 **메일이나 텔레그램으로 결과가 옵니다.**

시험지(문제·해설 이미지·정답표)는 파일이 아니라 **DB에 들어갑니다.** 서버가 재시작해도
시험지가 사라지지 않고, 나중에 외부 DB로 옮길 때 `DATABASE_URL` 한 줄만 넣으면 됩니다.

| 메뉴 | 내용 |
|---|---|

| 결과 | 점수 · 문항별 ⭕❌ · 단원별 정답률 · **틀린 문항 문제·해설 이미지** |

* 문제가 **한 문항씩** 나오고 바로 아래에서 답을 고릅니다. A4 한 장을 통째로 띄우면
  폰에서 글씨가 안 보이지만, 문항별로 잘린 이미지는 폰 폭에 딱 맞습니다.
* 33문항을 **6개씩 묶어서** 보여 줍니다. 묶음 버튼에 `✓`(다 함) / `(3)`(3개 함) 표시가 붙습니다.
* 남은 시간은 화면 맨 위에 **붙어서 따라옵니다.** 5분 남으면 빨갛게 바뀝니다.
* 시험지 전체가 필요하면 위쪽 `시험지 전체 보기 (인쇄용)` 를 펼치면 됩니다.
* 종이로 출력해 풀고 답만 옮겨 적어도 똑같이 됩니다.

답은 표시하는 즉시 저장되고, 시간이 끝나면 자동 제출·자동 채점됩니다.
틀린 문항의 **문제·해설 이미지는 채점 후 결과와 오답노트에서** 문항별로 볼 수 있습니다.
한 화면에 보여 줄 문항 수는 `app.py` 의 `PAGE_SIZE` 로 바꿉니다.

## 시험지 추가

선생님 화면 → **시험지·정답** → PDF 업로드 → 코드/제목/제한시간 → *등록하고 자동 분석*

**문제 + [정답 및 해설]이 한 파일에 있는 PDF**(족보닷컴 예상족보 형식)를 넣으면 자동으로:

| 자동 처리 | 내용 |
|---|---|
| 문항 분리 | 문제 페이지의 `1.` `2.` … 좌표를 찾아 문항별 이미지로 자름 |
| 해설 분리 | `1)[정답]` … 좌표를 찾아 문항별 해설 이미지로 자름 (단·페이지를 넘어가도 이어붙임) |
| 정답 추출 | `[정답] ③` 같은 객관식 정답을 자동 인식 |
| 단원 태깅 | 평면좌표 / 직선의 방정식 / 원의 방정식 / 도형의 이동 |

**주관식 정답만 손으로 넣으면 됩니다.** 한글 PDF가 수식을 전용 폰트 문자로 넣어서
텍스트로 안 읽히기 때문입니다. 등록 후 아래 정답표에서 `확인필요` 표시된 문항만
채우세요. 같은 화면의 *해설 이미지로 정답 확인하기* 를 열면 답을 보면서 입력할 수 있습니다.
시험지당 4~10개, 3분 정도입니다.

* `qtype` — `choice` 객관식(정답 1~5) / `short` 자동채점 / `essay` 선생님 확인

## 주관식·서술형 채점 (표기가 달라도 맞힙니다)

숫자든 식이든 **수학적으로 같으면 정답 처리**합니다. 학생이 정답과 똑같이 쓸 필요가 없습니다.

| 정답 | 이렇게 써도 정답 |
|---|---|
| `2√7` | `2root7` · `2sqrt7` · `2*sqrt(7)` · `sqrt(28)` · `2루트7` |
| `17/2` | `8.5` |
| `y=2x-5` | `2x-y-5=0` · `4x-2y=10` |
| `(x-4)²+(y-2)²=1` | `x^2+y^2-8x-4y+19=0` |
| `a=-1, b=-1, c=3` | `c=3, a=-1, b=-1` (순서 무관) · `-1, -1, 3` |
| `(12,5),(2,5),(4,-1),(-6,-1)` | 순서 바뀌어도 정답 |
| `1:2` | `2:4` |

입력칸 아래에 **그 문항에 맞는 입력 예시**가 자동으로 뜹니다
(좌표 문제면 "좌표로 입력 — 예) (3, 3)", 값 세 개면 "a=…, b=…, c=…").

판정이 안 서는 답(`±` 가 들어간 식, 문장 서술, 우리가 못 읽는 표기)만 선생님 화면으로
넘어갑니다. 첨부해 주신 **132문항 중 130문항이 자동채점**, 2문항만 선생님 확인입니다.

규칙을 바꾸고 싶으면 `mathcmp.py` 하나만 보면 됩니다. `python test_mathcmp.py` 로
86가지 경우를 한 번에 검사합니다.

### 시험지를 계속 쌓기 (GitHub 저장)

Streamlit Cloud는 서버가 재시작할 때 파일을 지웁니다. 그래서 앱에서 올린 시험지가
사라지지 않도록, **등록하면 GitHub 저장소에 `data/papers/<코드>.zip` 으로 자동 커밋**합니다.
재시작하면 저장소에서 다시 읽어 들이므로 시험지가 계속 누적됩니다.

**켜는 법** — 선생님 → 설정 → **GitHub 저장**

1. GitHub → Settings → Developer settings → Personal access tokens →
   **Fine-grained tokens** → *Generate new token*
2. Repository access = 이 앱 저장소 하나만 / Permissions → **Contents: Read and write**
3. 토큰과 저장소 이름(`LongS1eeper/exam-app`)을 넣고 **연결 테스트**

이후 흐름은 이렇습니다.

| 하는 일 | 저장소에서 일어나는 일 |
|---|---|
| PDF 등록 → 주관식 정답 채우고 **정답표 저장** | `data/papers/Q3.zip` 커밋 |
| 정답표 수정 | 같은 파일 갱신 |
| 시험지 삭제 | 파일 삭제 |

커밋이 생기면 Streamlit이 **1~2분 뒤 앱을 자동으로 다시 띄웁니다.** 정상이며, 그동안만
잠깐 느립니다. 시험 중에는 시험지를 등록하지 마세요.

**시험지·정답 화면 아래 `저장소 동기화`** 에서 앱과 저장소를 나란히 비교하고,
빠진 것을 한꺼번에 올릴 수 있습니다.

> 성적·오답노트는 이 방식으로 저장하지 않습니다. 제출할 때마다 커밋하면 앱이 계속
> 재시작해 버리기 때문입니다. 성적까지 누적하려면 DEPLOY.md 의 B안(Neon)을 쓰세요.

## 제출 알림

**기본값은 꺼져 있습니다.** 설정하지 않아도 채점은 정상 동작하고, 선생님 대시보드에 🔔로
표시됩니다. 폰으로 바로 받고 싶으면 아래에서 켜세요. (둘 다 켜도 됩니다)

### 텔레그램 (지금 쓰기로 한 방식)

텔레그램 앱에서 **@BotFather** 에게 `/newbot` → **선생님 전용 봇**과 토큰이 생깁니다.
알림은 그 봇과의 1:1 채팅방으로 옵니다. 학생은 이 봇의 존재를 모릅니다.

설정 → **텔레그램** 탭에 토큰을 넣고 → 봇에게 아무 메시지나 한 번 보낸 뒤 →
**내 chat id 찾기** → **테스트 발송**.

### 메일 (텔레그램 대신, 또는 함께)

선생님 → **설정 → 메일** 탭에서

1. 메일 제공자 고르기 (네이버 / 지메일 / 다음·카카오 / 직접 입력)
2. 보내는 계정과 비밀번호, 받을 주소 입력 — 보내는 주소와 받는 주소가 같아도 됩니다
3. **테스트 메일 보내기** → 메일함 확인 → **저장**

준비물은 메일 쪽 설정 하나뿐입니다.

| | 해야 할 일 |
|---|---|
| 네이버 | 메일 → 환경설정 → POP3/IMAP 설정에서 **IMAP/SMTP 사용함** 켜기.<br>2단계 인증을 쓰면 로그인 비밀번호 대신 **애플리케이션 비밀번호** |
| 지메일 | 2단계 인증을 켠 뒤 **앱 비밀번호** 16자리 발급 (일반 비밀번호는 막혔습니다) |

### 오는 내용

```
제목: [채점] 김민준 · 광성고 대비 1회 · 78.8점

🟡 김민준 · 광성고 대비 1회
```

## 파일 구조

```
exam_app/
├─ app.py           화면 (Streamlit)
├─ core.py          DB 계층 + 채점 로직   ← 채점 규칙은 여기만 보면 됩니다
├─ notify.py        제출 알림 (텔레그램 · 메일)
├─ gitstore.py      시험지를 GitHub 저장소에 누적
├─ mathcmp.py      수식 비교 (표기가 달라도 같은 답이면 정답)
├─ ingest.py        PDF → 문항·정답·해설 → DB
├─ pdfbackend.py    PyMuPDF ↔ poppler 자동 선택
├─ seed.py          data/papers 폴더 → DB 적재
├─ dbcheck.py       클라우드 DB 연결 점검
├─ test_core.py     자체 점검      →  python test_core.py
├─ test_mathcmp.py  채점 규칙 점검  →  python test_mathcmp.py
├─ mockup.py        학생 화면 예시 이미지 생성 (screens/)
├─ screens/         학생이 보는 화면 예시
└─ data/
   ├─ papers/       시험지 원본 (저장소에 함께 올려 두면 재시작 시 자동 복구)
   └─ exam.db       학생 성적 (개인정보 — .gitignore 로 제외)
```

## 점검

```bash
python test_core.py        # DB·채점·알림 (132문항 정답표 전수 점검 포함)
python test_mathcmp.py     # 채점 규칙 86가지
```

## 채점 규칙 바꾸기

* 표기 인정 범위 → `mathcmp.py` (`_WORD_SUB`, `FUNCS`)
* 채점 흐름 자체 → `core.py` 의 `judge()`

고친 뒤 `python test_mathcmp.py` 를 돌려 기존 규칙이 깨지지 않았는지 확인하세요.
